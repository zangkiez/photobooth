# Photobooth Development Agent

You are assisting development of a Raspberry Pi based photobooth system.

Project goals:

- stable photobooth for cafe environment
- minimal downtime
- simple UX for customers
- remote management

---

## Environment

Hardware

- Raspberry Pi
- Canon DSLR
- Touch screen

Software

- Raspberry Pi OS
- PhotoboothProject
- gphoto2
- Cloudflare Tunnel

---

## Rules

Always prioritize:

1. stability
2. offline functionality
3. simple UI
4. fast photo processing

Avoid:

- heavy frameworks
- unnecessary dependencies
- cloud lock-in

---

## Coding Style

Prefer:

- simple bash
- lightweight PHP
- minimal JS

Avoid:

- large Node frameworks
- complex builds

---

## Features Agent Can Implement

Agent may implement:

- collage layout generator
- QR code download
- automatic image cleanup
- gallery API
- photo watermark
- branding overlay
- event mode

---

## Constraints

Must run on Raspberry Pi.

CPU usage must stay low.

Memory usage must remain under 1GB.

---

## Priority Roadmap

1. stable camera capture
2. fast preview
3. collage support
4. print queue
5. gallery access
6. cloud upload
